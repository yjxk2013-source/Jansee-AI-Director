> **本文只定义画面里那块屏的尺寸与位置，其它一切（街景、楼体、天空、路面、材质、光线、气氛、镜头语言之外的元素）由你自由发挥。**

## 2. 屏的尺寸与位置（核心，请逐项核对）

**以下数字只用于你在内部构图时计算，绝对不要把它们写进画面。**

| 项 | 值 |
|---|---|
| 形状 | 正方形，宽高比 1 : 1 |
| 显示区（亮起来的那块面板） | 宽 907 × 高 907 |
| 显示区左上角 | (86, 411) |
| 显示区右下角 | (993, 1318) |
| 显示区中心 | (540, 864)，正好压在画面高度 45% 的线上 |
| 屏左右两侧剩余墙体 | 每侧 86（很窄，屏几乎贴到画面边缘） |
| 屏上方剩余空间 | 411（约画面的五分之一，天空与楼体） |
| 屏下方剩余空间 | 602（约画面的三分之一，街面与倒影） |
| 外框 | 显示区外围一圈深色边框，厚度约为显示区宽度的百分之一到二，要能看出厚度与转折，不是一条平涂的线 |

### 视觉校验（不靠数字也能对）

- **宽度**：屏的左右边缘几乎贴到画面左右边缘，中间只剩一条很窄的墙体。屏宽明显大于画面宽度的四分之三。
- **高度**：屏高略小于画面高度的一半。
- **形状**：正方形。不是横长方形，不是竖长方形。
- **位置**：屏的中心略高于画面正中间——大概在从上往下数的百分之四十五处，不是正中。

**不要把屏做成「墙中间挂了一幅小画」。屏是画面的绝对主体。**

---

## 3. 为什么是这组数字

合成端会把你这段视频当底，把用户的商品图精确叠进屏里的显示区。商品图按固定宽度 907 等比缩放，再居中放进显示区。所以：

- 显示区必须是**正方形**：三种常见图片比例（4:3 横 / 1:1 方 / 3:4 竖）进方屏，最差的一种也能填满 75%，没有任何一种会被放得特别小。
- 显示区宽度必须**恰好 907**：合成端用的是这个数，屏宽对不上，商品就会溢出屏外或缩在中间。
- 显示区中心必须**压在 45% 高度线**：太高会被顶部平台信息压住，太低会被底部字幕和按钮盖住。

---

## 4. 三种用户图片进屏后的落位（供你理解，不要画进背景）

| 图片比例 | 进屏后尺寸 | 占显示区面积 |
|---|---|---|
| 4:3 横图 | 907 × 680 | 75% |
| 1:1 方图 | 907 × 907 | 100%（满铺） |
| 3:4 竖图 | 680 × 907 | 75% |

图片永远完整显示、绝不裁切，所以装不满时会在屏内留下空带。**这正是显示区内部必须做暗、做抽象的原因**——空带露出来时不能有任何可辨识的内容跟商品抢注意力。

---

## 5. 绝对不许画进画面的东西（这一条最容易犯）

以下每一项都曾经被画进画面里，导致整段素材作废：

1. **任何数字或带单位的数字**——包括 `907`、`86`、`411`、`45%`、`14px`、`40px` 等等。任何形式都不行。
2. **尺寸标注、箭头、尺寸线、参考线、网格、坐标、刻度、比例尺**。
3. **型号、参数、版本号、网址、域名、二维码**。
4. **重复铺排的水印字、墙贴字母、玻璃上的字母组合**。
5. **中文字**。画面里不要出现任何中文。

**重要提醒**：如果你是照着我给的任何文字描述来生成，请注意「数字」只是描述，不是画面内容。看到「86」「411」「907」这类数字，请理解为"内部构图参数"，不要理解成"要标注出来的尺寸"。

---

## 6. 唯一允许出现的文字：JANSEE

画面里**只允许**出现 `JANSEE` 这一个英文字样，这是品牌方的明确要求。

| 规则 | 说明 |
|---|---|
| 拼写 | 必须是大写 `JANSEE`，逐字正确：J · A · N · S · E · E。错一个字母（如 JONSEE、JANSE、JANSEEE）整段作废 |
| 数量 | **全片只允许一处**，不得重复出现 |
| 位置 | 只允许在屏框正下方居中，贴着外框，或在外框下沿内侧一小条 |
| 字号 | 很小，不超过显示区高度的百分之六，像设备铭牌，不像广告标题 |
| 变体 | 不许加后缀（`.cn` / `.com` / `®` / `™`）、不许加中文、不许加任何其他字母或数字 |
| 中文品牌名 | **画面里不要出现「简兮」这两个中文字**，任何位置都不行 |

除 `JANSEE` 之外，画面里不出现任何其他文字。

---

## 7. 三条让尺寸成立的前提

这三条不属于「尺寸」，但任何一条破了，上面的尺寸就失去意义，素材直接作废：

1. **必须单镜头。** 10 秒内不许有剪辑点、切镜、叠化、闪白、场景变化。一个场景从第一帧撑到最后一帧。
2. **机位必须锁死。** 不推、不拉、不摇、不移、不变焦。屏在画面里的位置一帧不变。（哪怕只有百分之几的缓推也不行——在 907 宽的屏上会造成接近二十像素的漂移，商品就贴不准了。）
3. **先归一到 1080 × 1920 / 30 fps 再交付。** 其它分辨率或帧率先在出口处转好，不要交一个非 1080 × 1920 的文件。

---

## 8. 首帧参考图（最省事的做法）

随本文件配套一张 `screen-template-first-frame.png`（1080 × 1920）。

**请以它为构图基准：屏的位置、大小、形状、边框厚度必须与它完全一致，你只负责把那张图里的灰色背景替换成真实可信的场景。**

用参考图代替文字描述，是唯一能保证像素精确的方式——文字描述里的数字，容易被理解成"要标注在画面上的尺寸"。

---

## 9. 显示区内部（背景阶段）的尺寸相关要求

这部分和尺寸直接相关，因为它是商品图的底：

- 显示区内部只放**占位内容**：模糊色块、暗色渐变缓慢漂移。
- 平均亮度控制在画面的 25%–35%（明显低于商品，明显高于纯黑）。
- **不允许出现可辨识的场景、街道、楼宇剪影、灯光光斑、高光热点**——商品会叠在它上面，任何具体内容都会跟商品打架。
- 占位内容不得溢出显示区边界。

## 10. 交付时附一份元数据

```json
{
  "canvas": [1080, 1920],
  "slot": { "x": 86, "y": 411, "w": 907, "h": 907 },
  "shape": "square",
  "frame": 14,
  "single_shot": true,
  "locked": true,
  "fps": 30,
  "no_annotation": true,
  "brand_text": { "text": "JANSEE", "count": 1 }
}
```

| 字段 | 含义 |
|---|---|
| `slot` | 显示区左上角与宽高，必须与第 2 节完全一致 |
| `single_shot` | 全片一个镜头 |
| `locked` | 屏整段不动 |
| `no_annotation` | 画面无任何尺寸标注与文字 |
| `brand_text` | 画面中 `JANSEE` 的出现次数，必须是 1 |
