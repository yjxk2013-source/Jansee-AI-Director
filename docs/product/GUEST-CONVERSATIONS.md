# Guest conversation behavior

- Visitors can start a conversation without creating an account.
- Conversation text and attachment metadata are saved locally in the current browser only.
- The local history is capped at 30 conversations and can be searched from the navigation drawer.
- Original media files are not persisted by this local history feature.
- Guest history is not synchronized across browsers or devices and is not a cloud backup.
- Cloud history must replace this adapter after authentication and tenant-scoped persistence are implemented.
- Saving generated work, uploading source media to managed storage, and submitting a real generation job require the authenticated product flow.
