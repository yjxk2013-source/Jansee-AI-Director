## 审计原则
- V2 仅只读参考；不复制旧 BFF、旧支付接口、localStorage 业务真相源或旧页面结构。
- V4 的正式入口必须由 V4 API、持久化数据和权限规则支撑；不允许仅做视觉入口。
- 不重复呈现已有中心的数据：作品详情留在作品中心，积分/充值留在算力与交易中心，个人账户只提供身份资料和快捷入口。
- “源码存在”不等于“业务可用”；必须有服务端闭环和验收测试。

## 目标信息架构（简洁入口、成熟业务闭环）
1. **AI 导演创作中心**：所有创作方式由导演统一调度，不把旧模式做成互相割裂的工具菜单。
2. **作品中心**：作品列表、预览/下载、任务记录、有效期与删除状态。
3. **算力与交易中心**：钱包、套餐、充值、消费流水、订单、支付结果、退款申请/结果、发票凭证（若产品承诺）。
4. **增长与合作中心**：邀请推广、奖励记录、合伙人申请/资料、佣金明细、提现申请与审核结果。
5. **账户中心**：用户身份、UID、手机号/邮箱、账号安全、会话与退出；只放其他中心的快捷入口，不复制余额/作品统计。
6. **服务中心**：帮助文档、FAQ、客服/反馈、服务公告、用户协议、隐私与 AI 内容标识说明。

## 上线前必须完成的工程顺序
P0（基础账户体验）
- 账户中心显示稳定 UID、昵称、手机号/邮箱、注册时间；资料字段来源必须由 /auth/me 返回，不能由前端拼造。
- 已增加用户订单列表与积分流水查询 API，交易中心展示真实订单/流水；支付模拟保持非生产隔离。
- 个人页仅提供“作品中心”“算力与交易”“增长与合作”“服务中心”快捷入口，不重复展示余额、作品数量和订单明细。

P1（交易合规）
- 接入真实支付渠道、签名验签、幂等回调、订单状态机和对账。
- 明确退款政策及支付渠道退款 API；支持部分/全额退款状态、积分扣回、退款失败补偿、审计记录。
- 会员订阅权益必须与订单、有效期、额度限制真实联动；否则不展示会员等级/会员权益入口。

P2（增长与合作）
- 邀请码、邀请归因、奖励规则、奖励账本、反作弊和后台查询。
- 合伙人申请审核、区域/等级授权、佣金计算、退款冲正、结算周期和对账。
- 收款资料加密、提现审核、出款渠道、失败重试/撤销和完整审计。
- 签到如纳入：按用户时区的自然日唯一签到、奖励幂等、防刷和规则公示。

P3（服务）
- 帮助/FAQ/协议/隐私/公告页面。
- 反馈工单需要提交、状态跟踪、后台处理、通知闭环；若只提供邮箱，也必须有明确有效的客服渠道。

## 验收门槛
- 所有入口均有真实页面、API、持久化、权限校验、错误/空/加载状态。
- 涉及积分、现金、佣金、提现、退款的操作必须具备事务、幂等、防重复提交和审计记录。
- 无真实支付/出款配置时，不允许显示“已支付”“已退款”“可提现”等虚假状态。
- 个人中心不得重复展示钱包余额、作品数量和订单详情；这些数据只在所属业务中心作为真相源呈现。
- V2 不做任何修改；V4 不在 main 上开发；不提交、不部署，除非另行明确授权。

### V2 业务规则对照：尚需补齐的差异
- V2 提现前置资料包含分润类型（个人/企业）、实名信息、支付宝账号与支付宝收款码；个人需身份证信息，企业需营业执照及法人身份信息。V4 目前只有支付宝实名姓名/账号加密资料，没有个人/企业 KYC、证件核验与收款码凭证，因此不能直接开放生产提现。
- V2 佣金冲正规则是：订单退款后，未结算 pending 佣金直接 cancelled；已结算 settled 佣金仅标记 clawback，交由人工追偿，不静默改动已提现余额。V4 尚未接入 OPCPAY 退款事件与该冲正规则；必须按支付渠道退款成功事件执行冲正，并保留已提现款人工追偿账目。
- V2 提现协议包含按月累计劳务报酬预扣个税。V4 尚无税务计算、代扣与凭证记录；税务规则涉及法定义务，需财务/税务专业人员确认后再实现，不可直接照搬旧版公式。
- V2 的身份证字段/实名认证流程是旧系统模拟二要素校验，不构成可复用的真实 KYC 服务。V4 尚未接入有资质的实名核验服务、个人/企业主体资料与合规凭证流程；在完成合法性、隐私告知、数据最小化与服务商确认前，不应开放真实提现。为避免误开，当前 AppConfig.production=true 时已硬关闭收款资料写入和提现申请（503 PAYOUT_KYC_REQUIRED），开发环境仍可测试；待真实 KYC 服务与合规流程验收后再开放。
- V2 提现单笔 100–5,000 元、每日 3 笔/累计 10,000 元、1% 手续费最低 2 元、T+1；V4 本轮已补齐每日限额、短信二次验证、一次性敏感操作授权及 T+1 记录。
- V2 佣金仅对合伙人开通之后发生的会员/续费真实消费计提，最高两级 15% + 5%；V4 的订单计佣已检查合伙人开通时间与会员订单类型，规则保持一致。
