# 简兮 (JANSEE) 全局开发纪律

> 生效时间：2026-10-13
> 适用范围：所有功能开发（视频配音、字幕、封面、新视频风格及后续一切新能力）

## 核心流程

先盘点，再复用；先识别缺口，再设计新增；先批准，再实施；最后通过测试证明功能有效。

## 开发任何新功能前，Agent 必须先回答以下六个问题

1. 当前系统已经有什么能力？
2. 哪些能力可以直接复用，哪些只能有限扩展？
3. 哪些缺口是真正需要新增的？
4. 新功能会不会破坏现有契约、其他业务入口或冻结模块？
5. 怎样以最小改动完成需求，并证明没有回归？
6. 哪些文档、测试和能力边界需要同步更新？

## 预期结果

这样做不一定是每个功能都写更少的代码，但应该是：

- 更少的重复实现
- 更少的意外回归
- 更明确的架构边界
- 更容易预测的迭代成本
