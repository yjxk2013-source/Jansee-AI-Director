# 简兮 (JANSEE) 生产级状态机与高可用架构规范 (Architecture Whitepaper)

## 一、 异步任务状态机 (Job Lifecycle State Machine)

简兮系统将长耗时渲染任务抽象为确定性有限状态机（FSM），严禁前端阻塞等待：

```
       [提交素材]
           │
           ▼
     ┌───────────┐
     │  QUEUED   │ (进入任务排队队列，分配唯一 task_id)
     └─────┬─────┘
           │ 调度器拉取
           ▼
     ┌───────────┐
     │ ANALYZING │ (ASR 语音识别、断句分析、AI 导演分镜规划)
     └─────┬─────┘
           │
           ▼
     ┌───────────┐
     │ RENDERING │ (多轨音画对齐、TTS 合成、FFmpeg faststart 流式编码)
     └─────┬─────┘
           │
     ┌─────┴──────────┐
     ▼                ▼
┌───────────┐   ┌───────────┐
│ COMPLETED │   │  FAILED   │ (异常捕获、错误日志截断、资源自动回收并退费)
└───────────┘   └───────────┘
```

### 1. 幂等性与崩溃自愈
- 每个任务在创建时分配唯一 UUID，重复提交同一哈希素材返回已有任务状态（Idempotent）；
- 服务端异常重启时，处于 `ANALYZING` 或 `RENDERING` 的未完成任务自动标记为恢复中或安全退回重试队列。

## 二、 腾讯云 COS 私有回源与 CDN 302 秒播架构

为解决公网服务器 3Mbps-5Mbps 窄带宽瓶颈，系统实施大厂级媒资流转：

1. **纯净服务器原则**：云服务器本地磁盘**不保留任何视频和素材实体**，合成完毕立即推入对象存储（COS），本地临时素材即刻销毁；
2. **COS 私有回源鉴权**：存储桶设置为私有读写，杜绝外部直接遍历与流量盗刷；
3. **全链路 302 重定向播放**：客户端请求播放或下载时，后端 API 仅作租户鉴权校验，直接返回 `302 Found` 跳转至边缘加速域名 `https://cdn.jansee.cn/...`；
4. **视频起播优化**：FFmpeg 编码强制注入 `-movflags +faststart`，将 `moov` 索引原子放置于文件头部，配合客户端 HTTP Range 请求实现首帧秒级起播。
