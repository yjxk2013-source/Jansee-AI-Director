## 四、工程与性能红线

1. **单次流式渲染，严禁中间文件落盘**：所有运镜、转场、滤镜与字幕必须在单次 FFmpeg 调用中完成管道流式计算，严禁生成多份中间片段再二次压制。
2. **CPU 与并发硬保护**：在 4 核 4G 基准环境下，编码参数强制锁定 `libx264` + `preset=veryfast` + `threads=2`，最大并发度限制为 2，杜绝服务器 CPU 互锁与死机。
3. **Fail-safe 高可用兜底**：一旦合成中出现未知异常或超时（默认 20 分钟），任务自动触发熔断并原路退回用户积分，确保商家资金与配额安全。

## 五、V2 定版铁律（2026-10，用户验收后落盘）

以下为图片成片链路经端到端验收定版的硬性铁律，各子规范与代码行为冲突时**以本节为准**
（完整细则见 [`engine/04_visual_constitution.md`](file:///F:/janseeV2/docs/architecture/engine/04_visual_constitution.md) 附录 C）：

1. **禁调色**：主画面素材原色直出，严禁挂 eq/vignette/curves/lut；glass_layer 保护层只做空间模糊（gblur）。
2. **色彩空间还原标记（2026-10-12 定版）**：所有 RGB→YUV 转换点统一 `scale=out_color_matrix=bt709:out_range=tv`，
   输出容器加 `-colorspace/-color_primaries/-color_trc bt709 -color_range tv` 标签。
   这是色彩空间还原标记（非调色），修复裸 `format=yuv420p` 默认走 BT.601 导致播放器按 709 解释的发灰偏色
   （用户反馈「视频里的图片不是原图」）。工程落点：composer.js TO_YUV709。
3. **主标题单行**：主标题严禁拆行，单行自适应最多缩号 4 档（SINGLE_LINE_MAX_STEPS=4）；导演侧标题建议 ≤10 字。
4. **每图一镜动态扩镜**：N 张实拍图 = N 个图片镜，每图必现，严禁轮播丢弃。
5. **字幕单行轮播**：任意时刻画面仅一行字幕，长台词按时间均分轮播，严禁多行重叠。
