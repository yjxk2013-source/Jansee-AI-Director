# 免费带货成片工具 · 需求文档

> 版本 v1.1 · 2026-11-02 · **状态：搁置存档**（用户拍板，理由见下）
> 一句话：把简兮 JANSEE 的图片成片链路拆出来，做一个**免费网页工具**——用户上传商品图+填卖点，60 秒拿到「成片视频 + 文案 + 标题 + 封面 + 首评 + 话题」一条龙产出物。

> **搁置理由（2026-11-02 复盘）**：引流来的是**热流量**——看到实测视频还点进来的人本身就想做视频，信任已被视频建立，注册（手机号10秒）不构成断点。"零门槛白嫖层"是为冷流量设计的，对主路径多此一举。
> **替代动作（执行中）**：主站落地页放已有成片示例（火锅店成片 / AI 照妖镜）+「注册送积分，先做 3 条」，零新开发。
> **复活条件**：公司成立后做抖音小程序（视频下方挂锚点、平台内体验）时，本文档作为现成需求输入重启。

---

## 一、为什么做它（对用户原话的回应）

用户判断：光出文案没用，对话型 AI 都会；**图片成片整链路才是杀手锏**。这个判断成立，理由三条：

1. **真实门槛在"做"不在"写"**：小店主/带货新手里，会写文案的一大把，会把商品图变成带配音字幕 BGM 的竖屏成片的极少。我们填补的是"做"的坑。
2. **产出物六件套 = 一次发布所需的全部**：视频、文案、标题、封面、首评、话题——用户拿到手复制粘贴就能发，零学习成本。竞品（豆包/Kimi）只能给前两件的一半。
3. **自传播闭环**：免费版强制带「由简兮JANSEE生成」水印，用户每发一条视频就是一条活广告。工具即获客素材，这是文案工具做不到的。

## 二、获客漏斗数学（目标：3 个月 10000 注册）

```
短视频/笔记引流 → 工具页 UV → 完成出片 → 注册简兮（解锁高清无水印）
```

| 环节 | 假设转化率 | 说明 |
|---|---|---|
| 工具页 UV → 完成一次出片 | 40% | 流失在：不会填卖点/图片不合格 |
| 完成出片 → 注册 | 25% | 钩子：免费版 720p+水印，注册送 3 次高清无水印 |
| **UV → 注册综合** | **10%** | 即 10000 注册 ≈ 需 10 万工具页 UV |

10 万 UV 靠什么来：①自有账号矩阵发"工具实测"内容（照妖镜那类）；②用户生成视频的自带水印回流；③"免费带货视频生成"等关键词的搜索承接。前两条是主力。

## 三、免费版 vs 完整版 权益边界（防自杀式获客）

> 原则：免费版要"够爽愿意晒"，但要"不够用想升级"。

| 能力 | 免费工具版 | 简兮完整版（注册） |
|---|---|---|
| 出片次数 | 每设备/手机号 **每天 1 次** | 按产品现有积分体系 |
| 分辨率 | 720p | 1080p |
| 水印 | 片尾 3s「由简兮JANSEE生成」+ 角标 | 无 |
| 模板/音色 | 固定 1 套模板、1 个音色 | 全模板、全音色 |
| 时长 | ≤30s | 按产品能力 |
| 六件套产出 | 全给（文案/标题/封面/首评/话题不设限） | 全给 |

封面和文案不给限制——它们是分享诱饵，限制它们只会降低传播。

## 四、功能需求

### 输入（1 分钟填完）
- 商品图 1-9 张（拖拽上传，必填 ≥1）
- 商品名（必填）
- 核心卖点（textarea，选填，空则 AI 自己拆）
- 价格（选填，有则文案带"X.XX 元到手"）
- 平台选择：抖音/小红书/视频号（影响文案口吻和话题池）

### 输出（六件套）
1. **成片视频**：竖屏 1080×1920（免费版 720p），≤30s，3-6 镜，Ken Burns 运镜 + 腾讯 TTS 配音 + 逐句字幕 + BGM，片尾品牌卡
2. **标题**：3 条备选，按平台口吻（小红书带 emoji、抖音带钩子词）
3. **文案**：正文一段 + emoji 排版，可直接粘贴
4. **封面**：首帧图 + 大字标题（2 款备选），canvas 合成直接下载
5. **首评**：自评一条，含话题引导
6. **话题**：5-8 个平台相关话题标签，按热度排序展示

### 合规（必须）
- AI 标识：按 packages/subtitle-kit/aiBadge.js 现有口径，显式片尾标识 + 隐式元数据，一个字段都不许少
- 水印品牌露出：书面「简兮 JANSEE」首次全称，其余用「简兮」，与品牌三层规范一致
- 用户素材版权归用户，工具页明确声明；我们只存储 72h 供出片，到期删除

## 五、技术方案（复用优先，不重造）

### 复用 V2 现成资产
| 模块 | 来源 | 改动量 |
|---|---|---|
| 分镜生成（图→镜次+台词） | 图片成片链路分镜层 | 剥离成独立 API，口径不变 |
| TTS | packages/tts-kit 腾讯中台 + ttsProbe 探活 | 直接复用，句级重试+静音兜底照搬 |
| 合成参数 | 编码定版 veryfast/crf23/24fps | 原样搬 |
| 时长口径 | TTS 实测时长 +0.7s，LLM 不碰时长 | 原样搬（红线） |
| AI 标识 | packages/subtitle-kit/aiBadge.js | 直接复用 |
| ffmpeg | node_modules/ffmpeg-static | 服务端 spawn |

### 部署形态与最大技术风险
- 目标形态：Node 单端口 HTTP 服务（可走「发布为应用」通道），前端上传 → 服务端出片 → 返回 MP4 链接 + 六件套 JSON
- **⚠️ 上线前第一步验证（成败项）**：目标托管环境能否 spawn ffmpeg 子进程。用一个最小服务（express + ffmpeg-static + 一张图出 3 镜片）冒烟。**若被禁**：退路是 ffmpeg.wasm 浏览器端合成（服务器只出分镜/文案/TTS 音轨，编码在用户浏览器跑）——工程量约多 1-2 周，且低端手机可能编不动 720p 以上。先验证再定。
- TTS 密钥绝不下发前端，服务端代理调用。

### 单次成本估算（粗估，验证阶段实测修正）
- LLM（分镜+六件套文案）：几分钱/次
- 腾讯 TTS（≤30s 语音）：约 1 分钱/次
- 编码：CPU 15-60s/次
- 结论：单次成本可忽略，**真正的成本是防薅**——每日限次靠设备指纹+手机号验证，注册用户走产品积分体系。

## 七、部署位置与平台分发合规（2026-11-02 补）

### 放哪跑
- 工具是普通网页，挂在**自有官网域名**下（`jansee.cn/tools` 或 `tools.jansee.cn`），不在任何平台内。
- **首选部署：旧站腾讯云服务器（203.195.243.42）独立 Node 进程**——不碰旧站代码一行，同机新增独立服务，有现成公网 IP。ffmpeg spawn 验证就在这台机上做（M3 前置项）。
- 备选：等 V2 上云一起走——不推荐，获客等不起，会把钩子拖后几周。

### 平台内挂载的现实约束（2026-11-02 补）
- **资质硬约束**：抖音视频下方挂小程序/落地页组件、小红书号店组件，均需**企业主体**；公司未成立前走不通，评论区发链接会被吞。此路不是不做，是暂不可做。
- **中期规划（公司成立后第一优先）**：抖音小程序——视频下方挂锚点，用户平台内直接用工具，出片后引导注册拿高清版。这是"平台内体验"的完全体。
- **现阶段唯一合规挂链路径：视频号 → 公众号扩展链接 → 文章底部工具入口**（公众号本就是转化承接位）。
- **免费工具与注册送积分的关系（接力不是重复）**：工具页白嫖1次（零门槛尝甜头，不注册）→ 注册送积分做3次（尝到甜头后的承接）→ 付费。0 注册的当下，缺的是最上游获客理由，工具页就是给注册一个"先甜后解锁"的动机。

### 平台导流纪律（防限流/封号）
- ❌ 硬导流（会被限流/封号）：视频口播网址、画面二维码、评论区贴外链。
- ✅ 软导流（安全区）：视频内容本身是"AI 帮我做的带货视频"实测；主页简介写"AI 带货视频工具，搜简兮 JANSEE"；评论区小号问、大号回"搜简兮 JANSEE"。
- 与品牌词搜索承接闭环：用户被引导去搜「简兮 JANSEE」，搜索结果落地到官网工具页。

### 内容合规
- AI 标识：抖音/小红书均强制 AI 生成内容打标，工具输出必须带（aiBadge.js 口径，已在第四节）。
- 带货文案防极限词：LLM 提示词加约束（禁"最""第一""绝对"等广告法极限词），输出层再做一次关键词兜底过滤。

## 八、风险与对策

1. **ffmpeg 托管不可用**（最大风险）→ M3 前置验证，备选 wasm 方案已明确。
2. **被脚本薅羊毛** → 每日 1 次 + 出片需等 30-60s（本身就是天然限流）+ 异常频率封设备。
3. **伤自己产品** → 权益边界表已划定：免费版是"试用装"不是"平替"，升级动机（高清/无水印/多模板）持续存在。
4. **出片质量翻车**（首出片失败率是付费率命门的老问题）→ 免费版模板固定、参数冻结，变量最少，恰好是链路最稳的一档；失败自动重试 1 次，仍失败给文案兜底 + 致歉引导。
