# V4 商品窗口模板资产

此目录存放 V4 专用模板契约与经审核的背景资产。模板样例见 `manifest.example.json`，它处于 `pending` 状态且不可直接渲染。

每个模板使用稳定 `id` 和递增 `version`；`background.file` 必须是相对本 manifest 目录的清理后背景路径，窗口 `x/y/width/height` 使用 0–1 归一化坐标，原点为画布左上角。背景尺寸需与文件实际尺寸一致且为偶数像素。`padColor` 明确指定商品图等比 contain 后的留白颜色。只有状态为 `approved` 且审核信息齐全的模板可以渲染。

素材制作流程：保留原始创作文件；在离线编辑环节移除绿幕并检查被遮挡部分是否需要重绘；导出背景图；逐图人工标注窗口边界；确认比例和画布尺寸；由审核人检查清理瑕疵、窗口位置与商品遮挡后登记审核信息。无法从绿幕图恢复的内容必须由设计侧补图或重生成，不进行自动背景修复。

不得把 `绿幕/` 中未处理源图登记为审核通过资产。模板目录不属于 `packages/shared/frozenAssets.js` 管理范围，不允许修改任何现存冻结资产 ID 或配置。
