# 简兮后台管理系统 (JANSEE Admin Console)

> **定位**：面向 OPC 一人公司的 CEO 经营指挥中心  
> **设计语言**：Cyberpunk Command；深色网格、冷青主视觉、紫红辅助光效、数据优先、低干扰操作  

---

## 模块职能规划

1. **用户与商户中心**：商户入驻审核、会员等级、权益到期与封禁管控；
2. **算力与点数调度**：点数充值流水、LLM 消耗 Token 统计、TTS 与 GPU 算力资源负载；
3. **内容风控与合规审计**：商品实拍图合规审查、视频导出水印与违规拦截；
4. **多模态素材库管理**：商用 BGM 授权期管理、官方视频模板上下架、标签倒排索引维护。
