# 发布方案规则（Publish Rules）

> 定位：图片成片 / 视频配音 / 口播 三个版块共用的「发布方案」创作规则。
> 由 constitution.md 引用；各链路按需注入本文件全文，严禁内联复制到代码或其他人设文档（防双真相源漂移）。
> 字段契约（有哪些字段）以 constitution.md 的 JSON Schema 为准，本文件只管「每个字段怎么写」。
> 兜底清洗（LLM 缺字段/脏词/超长）由 @jansee/publish-kit 的 sanitizePublish 负责，本文件不重复约定。

## 四件交付物（JSON 顶层 publish 字段）

1. **caption（发布正文）**：给「刷到但还没看视频」的人的黄金吸睛钩子，严禁复述旁白台词——观众先听到再看文案，重复即减分，两边的信息必须互补。口语化、有网感，≤150字。结尾必须带 3-5 个**精准垂直的长尾话题标签**（深入具体圈层与使用场景，如 #藏在老巷子里的地道老味 #男士低调质感穿搭 #深夜治愈食堂，拒绝空洞无意义的泛标签），直击短视频算法精准推流。广告法红线：严禁极限词、医疗断言、虚假承诺。
2. **cover_title（视频标题）**：10~25字，短视频平台的爆款推荐标题（给创作者/商家在抖音/视频号/小红书发布时填写的视频主标题）。自带黄金吸睛钩子，直击利益点或痛点，句子完整、语意通顺（如「打工人宵夜救星！2块钱一包的光友酸辣粉丝，嗦一口直接封神」）。严禁半句话、严禁带“1080P”等技术参数字样。
3. **pinned_comment（置顶评论）**：破播放量的**高转化与互动钩子**（≤50字）。除了客观事实指引（门店位置/进店指引/福利）外，必须巧妙抛出一个让观众极有欲望在评论区回复、讨论、站队或好奇的互动问句（如隐藏吃法揭秘、选款二选一征集、真实生活体验互动），极大拉升评论区停留与算法推荐权重。严禁编造虚假承诺。
4. **post_time（发布时机）**：一句话。本地商家给饭点前 30 分钟建议，带货给晚 8-10 点黄金档，个人内容随性即可。

## 语气跟随场景人设

- 带货（sell）：促销钩子，紧迫感与利益点前置
- 探店（local）：烟火气 + 地址导向，像街坊推荐不像广告
- 个人（personal）：生活感分享，不营销

## 严苛红线（违者直接判定不合格）

1. 【严禁过时年份】：严禁出现“2024年”、“2023年”或任何历史年份字样！严禁套用过时年份网络口梗（如“在2024还能干嘛”），文案必须保持常青，需要指代时间一律用“现在 / 当下 / 今年”。
2. 【严禁虚构物流与承诺】：
   - **线上带货场景（sell）**：置顶评论与文案严禁自作主张编造用户未提及的物流方式（彻底禁止默认写“顺丰包邮”）、严禁编造未提及的售后承诺（如“7天无理由”）！未提及物流时，仅允许使用通用引导（如“正品现货 / 欢迎评论区交流”）。
   - **线下实体场景（local）**：**绝对禁止任何电商与物流词汇**（绝对禁止出现“现货直发”、“全国包邮”、“整箱发货/囤货”、“拍下”、“下单”、“快递”、“顺丰”等）！置顶评论只允许写：“同城位置/营业时间/进店指引/欢迎到店品尝”；正文与话题只允许打本地同城标签。

## 输出纪律

publish 是 JSON 顶层字段，与 shots/title 等同级输出；四件内容分工明确、互补不重复，缺一件即交付物缺角。
