## 个人创作免费（含一句话剪辑计费修正）
- 需求：个人创作入口进入的任务不消耗积分。实现时发现两个更大的事实：①前端此前**根本没把创作入口传给后端**，个人创作在服务端常被当成带货；②README 承诺一句话剪辑免费，但实际 jobs/语音精剪都在扣 200 积分。
- 方案：把「入口场景」作为统一事实来源。前端在导演规划/任务创建请求里透传 `creationScene`；后端 `withCreationSceneMarker()` 幂等写回提示词前缀供 worker/导演复用；`isFreeCreationEntry()` 统一判定 personal-creation / quick-cut 免费。
- 改动要点：jobs 创建时免费入口跳过余额检查与 hold，并强制单版；worker 领取 SQL 允许无 hold 的免费任务，完成/失败都不碰结算；语音精剪彻底不计费并打上 quick-cut 标记；renderer 把 quick-cut 视作 personal；UI 标注个人创作免费，去掉免费任务的 200 积分提示。
- 注意风险：免费判定依赖客户端声明的入口场景，API 调用方可以自称个人创作。若要防止滥用，需要服务端会话级入口签发，属于更大改造，当前未做。
- 验证：新增/更新 jobs、worker、worker-priority、speech-cut、director-api、renderer 相关测试；定向 52 项全过；完整套件 278 项中 276 过 1 失败 1 跳过，失败是既有 PWA manifest 图标缺失（用户此前删了 app-icon PNG 并改了 manifest，与本次无关）。`npm run typecheck` 仍是既有 3 个错误（batch-versions.ts:88、director.ts:232/262）；web build 与 `git diff --check` 通过。
