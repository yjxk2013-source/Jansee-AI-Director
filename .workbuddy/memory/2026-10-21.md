- 通读 README / AGENTS.md / 结构树说明 / CHANGELOG / package.json 及核心代码，完成项目全景理解。
- 关键事实：
  - 简兮 JANSEE = AI 短视频重构工场，Monorepo（npm workspaces：apps/* + packages/* + modules/*），版本 2.3.0（CHANGELOG 已见 2.4.0）。
  - 技术栈为「零框架原生栈」：前端是单文件 `apps/web/client/index.html`（约 1.16 万行，内联 CSS+JS），后端是原生 Node http 服务 `apps/web/server/index.mjs`（端口 3000），无 Express/Vite/React。
  - 前台开发服务：`scripts/dev-server.ps1`（PowerShell HttpListener，端口 5173，仅服务 client 目录，storage/ 特殊映射）；网关：`node apps/web/server/index.mjs` 或 `npm run dev:gateway`。
  - 出片主链路：`POST /api/v1/creation/create` → creation.mjs + director.mjs（LLM 分镜）→ packages 五大 kit（tts/audio/subtitle/cover/ffmpeg）+ modules/visual_engine_v4 → storage/outputs；旧 `/api/v1/video/produce` 已 410 下线；轮询 `GET /api/v1/creation/task/:id`（兼容 `/api/v1/video/task/:id`）。
  - 管理后台 API 在 `/api/v1/admin/*`（登录、用户、积分、订单、提现、合伙人、站内信、定价、站点配置等）。
  - 设计红线（AGENTS.md，改网站必守）：0 Emoji；2px 倒角微光幽灵边框按钮；商品图最多 9 张硬拦截；全站半透明黑曜石毛玻璃（rgba(10,10,14,0.5~0.7)+blur(20px)）；大白话业务命名；88 款视觉资产冻结于 packages/shared/frozenAssets.js。
  - 健康门禁：`npm run check:health`（scripts/check-health.ps1，查 0 Emoji 与架构完整性）。
- 产出：对话内输出架构与出片数据流图（SVG widget）+ 文字总结；未创建任何项目文件。
