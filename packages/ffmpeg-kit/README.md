# 简兮 (JANSEE) · FFmpeg 基础渲染服务 (@jansee/ffmpeg-kit)

> **状态**：**已完工并全面冻结 (FROZEN)**  
> **核心定位**：全平台底层音视频分析探测、并发保护与基础滤镜算力基建。

---

## 一、核心能力与工具清单

1. **高精度音视频探测 (`probe.mjs`)**：
   - 基于 `ffprobe` 快速探测媒体轨道时长、帧率、画幅尺寸、旋转角度与音频采样率；
   - 彻底取代前台估算，提供物理真实时长作为合成时间线基准。
2. **合成并发流控闸门 (`composeGate.mjs`)**：
   - 限制同时运行的高负载软编解码进程数，防止 CPU 吃满造成宿主机雪崩或 Docker 容器 OOM。
3. **音频无损变速 (`atempo.mjs`)**：
   - 基于标准 FFmpeg atempo 滤镜链实现 0.85~1.25 倍率语速调整，不产生音调畸变。
4. **宪法级动效参数表 (`constitutionEffects.js`)**：
   - 规范全平台统一的呼吸闪避、淡入淡出、微距字幕等物理参数。

---

## 二、冻结红线纪律 (Freeze Redlines)

1. **底层参数禁止篡改**：并发闸门限制与探测超时机制直接关系服务器运行稳定性，严禁随意扩大或取消限流；
2. **严禁引入系统外部不可移植依赖**：保持对 `ffmpeg-static` 与 `ffprobe-static` 的纯净依赖。
