# 简兮 (JANSEE) · 字幕与国标合规中台 (@jansee/subtitle-kit)

> **状态**：**已完工并全面冻结 (FROZEN)**  
> **核心定位**：全平台四大业务版块（图片成片 / 视频配音 / 出镜口播 / 切片分镜）统一字幕渲染与国标 AIGC 双标识中台。

---

## 一、核心契约与合规规范

1. **国标 GB 45438-2025 双标识规范（单一真源）**：
   - **显式标识**：开头 2.5s「AI 生成」+ 结尾 2.5s「本视频由 AI 生成 · JANSEE」，字号严格等于短边 5%（1080 宽即 54px）；当成片存在 CTA 收束卡时尾标自动由收束卡原生承载，避免双层重叠；
   - **隐式元数据**：`buildAiMetaTags` 统一输出标准 MP4 `udta` 元数据标签，供抖音、快手等平台推荐算法识别 AIGC 防限流。
2. **发丝级微距字幕渲染 (`subtitle.js`)**：
   - 生成 SRT 时间轴或基于 drawtext/PNG 发丝级微距图层渲染；
   - 自动行末标点剥离、标点单独成行熔断与两行最大字数钳制。
3. **字体单一真源**：
   - 严格锁定 `materials/fonts/noto-sans-sc/`（思源黑 OFL 开源授权），零版权风险，严禁调用系统字体。

---

## 二、冻结红线纪律 (Freeze Redlines)

1. **严禁修改国标法定要素**：必须同时包含“AI（或人工智能）”与“生成（或合成）”，字号不得低于短边 5%；
2. **严禁删除 MP4 udta 元数据注入**：隐式元数据是各大短视频平台合规通行证，必须强制携带。
