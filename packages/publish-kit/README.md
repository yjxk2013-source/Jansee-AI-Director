# 简兮 (JANSEE) · 发布方案五件套共享层 (@jansee/publish-kit)

> **状态**：**已完工并全面冻结 (FROZEN)**  
> **核心定位**：全平台四大业务版块（图片成片 / 视频配音 / 出镜口播 / 切片分镜）统一发布文案生成、广告法合规清洗与封面海报关联交付物。

---

## 一、核心能力与五件套交付物

1. **发布方案五件套标准契约**：
   - `cover_url`：高清纯净宣发封面海报链接（无字幕、无角标，支持前端一键下载）；
   - `caption`：抖音/小红书/快手带货文案（含热门标签与黄金前三秒钩子）；
   - `cover_title`：封面主标题吸睛大字；
   - `pinned_comment`：互动引导置顶评论；
   - `post_time`：行业流量高峰建议发布时机。
2. **广告法红线词表与温和替换 (`sanitizePublish`)**：
   - 过滤“全网最低”、“第一名”、“顶级”、“特效”等极限词与医疗断言；
   - 采用温和替换字典（如“全网最低”→“这个价”，“顶级”→“硬核”），确保句子自然通顺不生硬。
3. **交付物安全脱敏**：
   - 仅白名单透传五件套纯文本与相对 URL，调试埋点字段（如 `_banned_hits`）一律屏蔽，杜绝泄露内部架构。

---

## 二、冻结红线纪律 (Freeze Redlines)

1. **五件套字段契约禁止破坏**：前端影院与网关已针对五大字段形成强依赖绑定，禁止重命名或删减；
2. **零 Emoji 铁律**：除用户台词外，系统默认发布提示与标签禁止引入任何 Emoji。
