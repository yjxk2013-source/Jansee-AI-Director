# 简兮 (JANSEE) · 语音合成中台 (@jansee/tts-kit)

> **状态**：**已完工并全面冻结 (FROZEN)**  
> **核心定位**：全平台四大业务版块（图片成片 / 视频配音 / 出镜口播 / 切片分镜）统一 TTS 配音与多音色调度中台。

---

## 一、核心能力与契约规范

1. **腾讯云单通道极速合成 (`synthesizeLines` / `tts.js`)**：
   - 支持多段台词并发合成与时长高精度实测（精确到毫秒）；
   - 具备长文本自动断句分片与呼吸余量停顿支持。
2. **多音色智能调度与保活探活 (`voices.js` / `ttsProvider.js`)**：
   - 统一管理音色表与场景推荐匹配；
   - 服务启动自动执行接口探活，异常自动熔断降级。
3. **接口契约锁定**：
   - 输入台词数组与音色 ID，统一输出落盘音频路径与精确时长，支持全局语速安全钳制（0.85~1.25）。

---

## 二、冻结红线纪律 (Freeze Redlines)

1. **严禁修改时长测算口径**：图片成片与视频配音高度依赖实测音频时长定帧，禁止估算凑整；
2. **严禁引入未经授权的音色 ID**：音色库必须与业务前端选项保持绝对一致。
