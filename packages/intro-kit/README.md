# 简兮 (JANSEE) · 开场微光与宣发封面中台 (@jansee/intro-kit)

> **状态**：**已完工并全面冻结 (FROZEN)**  
> **核心定位**：全平台四大业务版块（图片成片 / 视频配音 / 出镜口播 / 切片分镜）统一开场包装与纯净封面输出服务。

---

## 一、核心能力与契约

1. **电影级 100% 纯黑羽化开场遮罩 (`intro.js`)**：
   - 上半部分自 `rgba(0,0,0,1)` 向下延展纯黑渐变羽化至完全透明（纵深 400px）；
   - 大标题、英文字标与留白短句在各种浅色、复杂背景下反差极致锐利；
   - 画面中间主体区域 100% 透明贯穿，绝不死黑遮挡背景。
2. **纯净宣发封面海报合成器 (`cover.js` / `composePureCover`)**：
   - 多模态自适应：源视频定点在 1.0s 抽取纯原画，静态素材直接读取原图；
   - 使用 Sharp 毫秒级与 1080×1920 电影级遮罩透明贴片压合；
   - **纯净度 100%**：绝对隔离口播台词字幕与 AI 角标干扰，供创作者直接下载用于各大平台宣发。
3. **标准滤镜图构建器 (`buildIntroOverlayFilter`)**：
   - 统一输出 FFmpeg `fade=in` + `fade=out` + `overlay enable` 滤镜片段，各业务版块零重复实现。

---

## 二、冻结红线纪律 (Freeze Redlines)

1. **严禁降低羽化黑度**：顶部第一段严禁改回半透灰色，必须保证 100% 纯黑基底；
2. **严禁在封面中混入正片台词或AI水印**：封面海报必须维持 100% 宣发级纯净；
3. **零 Emoji 铁律**：所有开场文案与标签严禁引入系统 Emoji。
