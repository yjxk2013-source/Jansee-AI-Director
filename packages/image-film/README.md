## 一、核心能力与交付全链路

1. **V4 独立视觉引擎全链路编排**：
   - 调度 7 类定稿视觉资产（镜间平滑转场、Ken Burns 分镜运镜、15 款片尾收束卡、思源黑体与杂志排版）；
   - 严格执行 9 张图上限拦截与第一图洞位长宽比锁定。
2. **纯实测音画对齐**：
   - 消费 `@jansee/tts-kit` 逐镜实测语音时长（带 0.7s 呼吸停顿），按实测秒数精确定帧，杜绝按字数估算造成的音画错位。
3. **收束卡单层尾标保证**：
   - 彻底解耦滤镜层，片尾收束卡统一由 `@jansee/ending-kit` 内置国标尾标，外部绝不再重复叠贴。
4. **全链路纯净宣发封面海报**：
   - 消费 `@jansee/intro-kit` 的 `composePureCover` 自动生成 `cover.jpg`，100% 隔离口播台词字幕与 AI 角标，支持用户一键下载。
