# 简兮 (JANSEE) · 全栈共享基础工具库 (@jansee/shared)

> **状态**：**已完工并全面冻结 (FROZEN)**  
> **核心定位**：全平台跨模块寻址与运行时路径映射基础库。

---

## 一、核心能力与规范

1. **统一素材资产库寻址 (`assetsPath.mjs`)**：
   - 自动适配本地开发路径、Monorepo 嵌套包路径及生产环境 Docker 容器根目录；
   - 对外提供 `assetsDir`，统一解析 `materials/` 多模态资产（BGM 曲库、字体字库、SVG 贴图等）。

---

## 二、冻结红线纪律 (Freeze Redlines)

1. **严禁硬编码宿主机绝对路径**：必须通过 `assetsDir` 进行动态环境寻址；
2. **保持零依赖轻量性**：本包仅作为纯路径工具，禁止引入庞大的业务逻辑依赖。
