# 简兮 (JANSEE) · 主播人设与表达 DNA 库 (@jansee/anchor-kit)

> **状态**：**已完工并阶段性冻结 (FROZEN - 投放市场观察中)**  
> **核心定位**：全平台四大业务版块统一主播人设标签、表达 DNA 提取与剧本大模型提示词注入库。

---

## 一、核心能力与数据规范

1. **多场景主播画像库 (`anchors.js`)**：
   - 包含专业带货、真诚探店、生活博主等细分场景主播画像与口播调性指导。
2. **主播表达 DNA 计算与映射 (`dna.js`)**：
   - 提取剧本文案的行文节奏、语气词密度与钩子力度，生成易读的“主播 DNA 风格标签”；
   - 随成片交付结果透传至前端影院卡片，供商家查看本次成片的表达人格。
3. **主播抽选与兜底 (`pick.js`)**：
   - 支持按场景与业务参数确定性抽选匹配的主播人设。

---

## 二、冻结红线纪律 (Freeze Redlines)

1. **当前阶段性冻结锁定**：投放市场观察商家与创作者反馈前，暂不增加或修改现有画像规则与 DNA 映射；
2. **零 Emoji 铁律**：所有主播标签名称与提示词模板严禁包含系统 Emoji。
