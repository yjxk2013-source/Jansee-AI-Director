# 简兮 (JANSEE) · 音频混音与 BGM 中台 (@jansee/audio-kit)

> **状态**：**已完工并全面冻结 (FROZEN)**  
> **核心定位**：全平台四大业务版块（图片成片 / 视频配音 / 出镜口播 / 切片分镜）统一情绪配乐与人声动态闪避中台。

---

## 一、核心能力与混音规范

1. **情绪选曲引擎 (`selectBgmByEmotion`)**：
   - 消费 `materials/audio/` 官方曲库，支持 30+ 细分情绪目录与 8 大核心归一重定向（`MOOD_REDIRECT`）；
   - 具备内存防重与轮转重置机制，同任务连续出片不撞曲。
2. **两段式 Sidechain 动态人声避让混音链**：
   - 根据口播时间窗精确施加音量包络（人声说话时音乐平滑压低至 0.15，人声间隙与呼吸停顿平滑回升至 0.85）；
   - 彻底解决 BGM 喧宾夺主压过口播的痛点，确保听觉清晰与大片氛围兼备。
3. **循环回放与音轨降混**：
   - 视频时长超出音乐原长时，通过流式循环对齐；无配音时纯音乐完整放行。

---

## 二、冻结红线纪律 (Freeze Redlines)

1. **严禁修改两段式音量闪避参数**：0.15 人声压低阈值与 0.85 恢复阈值经过实测调优，禁止擅自修改；
2. **严禁破坏情绪映射契约**：新增情绪曲库必须遵循现有目录结构，禁止删除基础重定向规则。
